# 🌌 Building Digital Masterpieces

> **"Code is art, and AI is the brush."**  
> 비즈니스의 본질을 통찰하고, AI를 도구 삼아 최상의 가치를 지닌 디지털 걸작(Masterpiece)을 빚어냅니다.

Antigravity AI와 협업하여 구축한, 현대적이고 인터랙티브한 프리미엄 개발자 포트폴리오입니다. 최첨단 기술 스택과 AI 중심의 개발 프로세스를 통해 단순한 코딩을 넘어 기술의 예술적 가치를 실현합니다.

## 🚀 Tech Stack

### Frontend & Core
- **React 19**: 최신 버전의 React를 활용한 강력한 UI 라이브러리.
- **Vite 8**: 초고속 빌드 도구를 통한 쾌적한 개발 환경 구성.
- **TypeScript 6**: 엄격한 타입 체크를 통한 안정적인 코드 베이스 확보.
- **TanStack Router**: 파일 기반 라우팅 시스템을 통한 체계적인 페이지 관리.

### Styling & Visuals
- **Tailwind CSS v4**: 차세대 CSS 프레임워크를 활용한 고성능 스타일링 및 유연한 UI 설계.
- **Lucide React**: 미니멀하고 현대적인 아이콘 라이브러리.
- **Modern Design Principles**: 다크 모드, 글래스모피즘(Glassmorphism), 마이크로 애니메이션 적용.

## 🤖 AI-Powered Development (with Antigravity)

이 프로젝트는 **Antigravity AI**와의 긴밀한 페어 프로그래밍을 통해 완성되었습니다. AI는 단순히 코드를 작성하는 도구를 넘어, 아키텍처 설계와 디자인 의사결정의 핵심 파트너로 참여했습니다.

### 1. UI/UX Design Generation
AI가 제시한 프리미엄 디자인 가이드를 바탕으로 일관된 시각적 언어를 구축했습니다. 다크 테마의 깊이감 있는 배경과 강조 컬러(Rose, Indigo)의 조화를 통해 방문자에게 강렬한 첫인상을 남깁니다.

### 2. SSoT (Single Source of Truth) Data Refactoring
복잡한 프로젝트 자산을 효율적으로 관리하기 위해 데이터 구조를 지능적으로 설계했습니다.
- **이미지 자동 폴백**: 월별 내역 이미지를 프로젝트 대표 이미지로 자동 변환하여 유지보수 비용을 최소화했습니다.
- **통합 미디어 시스템**: 이미지와 유튜브 데모 영상을 하나의 갤러리 흐름으로 묶어주는 지능형 렌더링 로직을 구현했습니다.

### 3. Enhanced Interactive Experience
- **지능형 라이트박스**: 단순히 이미지를 확대하는 것을 넘어, AI가 분석한 작업 상세 내역(Description)과 진행 인덱스를 실시간으로 연동하여 풍부한 맥락 정보를 제공합니다.
- **시각화된 경력 타임라인**: 수치와 텍스트 위주의 경력을 동적인 타임라인 그래프로 변환하여 시각적 직관성을 높였습니다.

### 4. Quality Assurance & Maintenance
AI는 지속적인 정적 분석과 타입 체크를 통해 발생 가능한 런타임 오류를 사전에 차단했습니다. 복잡한 TypeScript 제네릭과 유니온 타입을 명확하게 정의하여 견고한 코드 품질을 유지하고 있습니다.

## 🧭 Operational Philosophy & AI Collaboration

이 프로젝트는 개발자의 운영 철학을 바탕으로 AI의 제안을 비판적으로 수용하고 고도화한 **공동 창작의 결과물**입니다.

### 💡 Core Operational Philosophy
> "관리의 최소화, 경험의 극대화 (Minimal Maintenance, Maximal Experience)"
- 데이터 입력은 한 번만 하되, 노출은 다각도로 이루어지는 **Single Source of Truth(SSoT)** 원칙 고수.
- 텍스트 위주의 정보를 지양하고, 미디어와 그래픽을 통한 **직관적인 서사 전달** 지향.

### 🤝 AI Suggestion & User Refinement

| Category | AI's Creative Suggestion | User's Strategic Refinement |
| :--- | :--- | :--- |
| **Data Structure** | `imageUrl` 옵션화 및 첫 번째 Task 이미지 자동 폴백 제안 | **`hidden` 플래그 도입**: 타임라인엔 핵심만, 상세 모달엔 전체를 보여주는 세밀한 노출 제어 구현 |
| **Visual Resume** | 날짜 위주의 경력을 기간/강도 기반의 막대 그래프로 시각화 제안 | **가독성 튜닝**: 폰트 사이즈 조정 및 `baseline` 정렬 최적화를 통해 전문성 강화 |
| **Project Gallery** | 유튜브 영상을 갤러리의 마지막 항목으로 자동 삽입하는 로직 제안 | **인라인 데모 통합**: 외부 탭 이동 없이 모달 내에서 즉시 재생되는 UX로 고도화 |
| **Lightbox UI** | 확대 이미지 하단에 인덱스 및 설명 표시 제안 | **레이아웃 재설계**: 정보를 한 줄로 묶은 왼쪽 정렬 캡슐 UI로 변경하여 시각적 간결함 완성 |
| **Content Strategy** | 연도별 데이터 분리 및 모듈화 구조 제안 | **히스토리 아카이빙**: 과거 구동 사이트의 유튜브 링크 및 상세 회고록을 시스템에 완벽 통합 |

## 🏗️ Engineering for Maintainability

장기적인 유지보수 효율을 높이고 휴먼 에러를 방지하기 위해 소프트웨어 공학적 원칙을 엄격히 적용했습니다.

### 1. 아토믹 디자인 패턴 기반 컴포넌트 설계 (Atomic Design)
UI의 일관성과 확장성을 위해 컴포넌트를 계층화하여 관리합니다.
- **Atoms**: 버튼, 배지, 아이콘(Lucide), 타이포그래피 등 가장 작은 UI 조각.
- **Molecules**: 원자들의 조합으로 구성된 의미 있는 단위 (예: 인덱스 배지와 설명이 결합된 정보 그룹, 타임라인 항목).
- **Organisms**: 복잡한 기능을 수행하는 독립적 컴포넌트 (`ProjectCard`, `ExperienceSection`, `ProjectModal` 등).
- **Templates & Pages**: 데이터와 유기체가 결합되어 완성되는 최종 화면 레이아웃.

### 2. 체계적인 디자인 개발 (Design Development)
- **Consistent Design Tokens**: 전용 컬러 시스템(Indigo, Rose, Cyan)과 글래스모피즘(Glassmorphism) 스타일을 규격화하여 프로젝트 전반에 적용했습니다.
- **Micro-Interactions**: 모든 상호작용 요소에 일관된 호버(Hover) 효과와 매끄러운 트랜지션을 적용하여 사용자 경험의 밀도를 높였습니다.
- **Visual Hierarchy**: AI와의 협업을 통해 시각적 위계를 최적화하고, 중요한 정보가 직관적으로 전달되도록 설계했습니다.

### 3. 관심사 분리 (Separation of Concerns)
- **Data & Schema Isolation**: 모든 프로젝트 및 이력 데이터는 전용 데이터 파일(`src/data/`)에서 관리되며, 명확한 인터페이스(`types.ts`)를 통해 규격화됩니다.
- **Logic Encapsulation**: 필터링, 정렬, 모달 제어 등 복잡한 비즈니스 로직은 **Custom Hooks(`useProjectLogic.ts`)**로 캡슐화하여 UI 컴포넌트와의 의존성을 최소화했습니다.

### 4. 하드코딩 제한 및 휴먼 에러 방지 (Anti-Hardcoding)
- **Single Source of Media**: 이미지 경로를 중복 기입하지 않고, 데이터 객체 내에서 한 번만 정의하면 카드와 상세 모달에 자동 반영되는 시스템을 구축했습니다.
- **Intelligent Media Parsing**: 유튜브 링크 입력 시 정규표현식을 통해 ID를 자동으로 추출하고 임베드 코드를 생성하여 수동 입력 에러를 방지했습니다.
- **Automatic Image Fallback**: 대표 이미지가 누락된 경우 태스크 리스트의 첫 번째 이미지를 자동으로 선택하도록 설계하여 UI 깨짐을 방지했습니다.
- **Strict Type Checking**: TypeScript의 강력한 타입을 통해 데이터 입력 시점에 발생할 수 있는 오타나 잘못된 속성 할당을 실시간으로 감지합니다.
